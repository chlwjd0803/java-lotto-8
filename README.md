# 로또
##  핵심 기능

* **로또 구입비용 입력**: 1,000원 단위의 정수를 입력받습니다.
* **구입 로또 생성**: 몇개 구매했는지 정보를 표시하고, 가격에 맞게 구입된 로또들의 번호를 랜덤으로 지정합니다. 이때 로또들의 번호는 오름차순으로 정렬합니다.
* **당첨번호 입력**: 쉼표(`,`)로 구분된 1~45 사이의 정수인 당첨번호 6개를 입력합니다.
* **보너스 번호 입력**: 1~45 사이의 정수인 보너스 번호를 입력합니다.
* **당첨내역 출력**: 당첨번호와 로또들을 비교하여 당첨내역을 출력합니다.
  * 당첨기준
    * 3개 일치 (5,000원)
    *  4개 일치 (50,000원)
    *  5개 일치 (1,500,000원)
    *  5개 일치, 보너스 볼 일치 (30,000,000원)
    *  6개 일치 (2,000,000,000원)
* **수익률 출력**: 당첨결과에 대한 수익률을 소수점 둘째자리에서 반올림하여 출력합니다.
  * 수익률 = 당첨 상금의 합 / 로또 구입비의 합
